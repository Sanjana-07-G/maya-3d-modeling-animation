# Interior Room Model

## Overview

This project was created during my high school 3D Modeling & Animation course (2023–2024) using Autodesk Maya.

The project showcases a furnished interior living room modeled in 3D and presented using a 360° turntable animation to display the scene from all angles.

## Skills Practiced

- 3D Modeling
- Scene Composition
- Object Placement
- Material & Texture Application
- Lighting
- Camera Setup
- Turntable Animation
- Rendering
