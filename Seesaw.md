# Seesaw Animation

## Overview

This project was completed during my high school 3D Modeling & Animation course (2023–2024).

The animation was created by following instructor-guided tutorials in Autodesk Maya to learn animation fundamentals.

## Skills Practiced

- Keyframe Animation
- Object Transformations
- Timeline Editing
- Motion Timing
- Basic Rendering

## Software

Autodesk Maya
