# Seesaw Animation

## Overview

This project was completed during my high school 3D Modeling & Animation course (2023–2024) at Lebanon Trail High School.

The animation was created using Autodesk Maya by following instructor-guided tutorials to learn the fundamentals of animation.

## Skills Practiced

- Keyframe Animation
- Object Transformations
- Timeline Editing
- Animation Timing
- Basic Rendering

## Software

- Autodesk Maya
